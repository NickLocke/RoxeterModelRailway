# PIC Based CBUS Modules

## Main Boards

- CAN4DIGIT - CANLED64 variant with four seven segment displays.
- CANARGB - CANARGB driving up to 255 RGB LEDs
- CANBIP - CANBIP with eight bipolar outputs.
- CANDISP - CANDISP (64 outputs)
- CANMIO - 
  - CANMIO4S4I - CANMIO with four servo outputs and four inputs.
  - CANMIO6I2S - CANMIO with six inputs and two servo outputs.
  - CANMIO8I - CANMIO with eight inputs.
  - CANMIO8O - CANMIO with eight outputs (via ULN2803, so active low).
  - CANMIO8O25 - CANMIO with eight outputs (via ULN2803, so active low) - older PIC.
  - CANMIO8OX - CANMIO with eight outputs (via TBD62781APG, so active high).
  - CANMIO8S - CANMIO with eight servo outputs
- CANSCAN - CANSCAN (128 inputs)

## Daughter Boards

- MIOADD8I - MIOADD with eight inputs.
- MIOADD8O - MIOADD with eight outputs (via ULN2803, so active low).
- MIOADD8OX - MIOADD with eight outputs (via TBD62781APG, so active high).
- MIOADDSVO - MIOADSVO with eight servo outputs.
- MIODTC8 - MIO8DTC with eight track detection inputs.
