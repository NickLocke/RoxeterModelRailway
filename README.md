# Roxeter Model Railway
The model railway is being constructed in N scale and occupies two walls of the garage in an L-shape.

The main track layout is two concentric ovals, compressed in the middle to form a dog-bone, giving the impression of a four track main line. At one end of the layout, parallel tracks exist to give stabling space for additional trains. A branch line and terminus will be added in due course, with the layout having appropriate point work to allow trains to enter and exist the branch line.

Having prototypical signalling is a key part of the modelling approach, so the layout is controlled by three [signal box panels](ControlPanels).

The layout makes heavy use of [CBUS modules](CBUSModules)

The code has been structured into a number of [libraries](ArduinoLibraries) to allow for re-use.

There are some quirks around how the development environment is configured and with the structure of the C++ code. They have been documented [here](Configurations), so far as memory allows.

Information on how [CBUS events](CbusEvents) are used on Roxeter is provided.
